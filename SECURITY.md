# Security policy

PCB Maker runs entirely in your browser. It has no backend, and the files you load are never uploaded. Security issues are still possible, for example a crafted Gerber or zip file that makes the app misbehave, or a vulnerable dependency.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub instead: go to the [Security tab](https://github.com/ronaldmourik/3d_pcb_maker/security) and click **Report a vulnerability**.

Include what you found, how to reproduce it, and any files needed to trigger it. You can expect a first reply within a week.

## Supported versions

Only the latest version on `main` (the one published at https://ronaldmourik.github.io/3d_pcb_maker/) gets fixes.
